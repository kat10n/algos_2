## 2. Типы чисел и переполнение

| Тип | Диапазон | Когда |
|-----|----------|-------|
| `int` | ±2.1·10⁹ | по умолчанию |
| `long long` / `int64_t` | ±9.2·10¹⁸ | суммы, произведения, всё что может быть > 2·10⁹ |
| `unsigned` / `size_t` / `uint64_t` | 0 … 1.8·10¹⁹ | размеры, битовые операции |
| `double` | ~15 значащих цифр | вещественные |

**Ловушки:**
```cpp
int a = 100000, b = 100000;
long long bad  = a * b;              // ПЕРЕПОЛНЕНИЕ: умножение идёт в int, потом приводится
long long good = 1LL * a * b;        // ок: 1LL — это long long, дальше всё считается в long long

vector<int> v;                       // пустой
for (size_t i = 0; i < v.size() - 1; ++i)  // v.size() - 1 = 0 - 1 = 18446744073709551615 (!!!)
// size_t беззнаковый, "минус один" заворачивается в огромное число.
// Поэтому я везде пишу int n = (int)a.size(); и дальше работаю с int.
```

`ssize_t` в коде препода — знаковый size_t (может быть −1), нужен для цикла `for (i = n-1; i >= 0; --i)`.
С `size_t` условие `i >= 0` всегда истинно → бесконечный цикл. Проще использовать `int`.

## 3. vector

```cpp
vector<int> a;              // пустой
vector<int> b(5);           // 5 нулей
vector<int> c(5, 7);        // 5 семёрок
vector<vector<int>> g(n);   // n пустых векторов (например, списки смежности или "карманы")

a.push_back(3);             // добавить в конец, амортизированно O(1)
a.size();                   // размер (тип size_t!)
a.back();                   // последний элемент
a.pop_back();               // удалить последний
a.reserve(1000);            // заранее выделить память (меньше перевыделений)
a.clear();                  // очистить
a.swap(b);                  // обменять содержимое за O(1) (просто меняются указатели внутри)
a = b;                      // КОПИРОВАНИЕ за O(n)!
```

## 4. Ссылки `&` и `const &`

```cpp
void f1(vector<int> a)        { a[0] = 1; } // получает КОПИЮ: O(n) на копирование, исходный не меняется
void f2(vector<int>& a)       { a[0] = 1; } // ССЫЛКА: работает с оригиналом, исходный меняется
void f3(const vector<int>& a) { /* a[0] = 1; — ошибка компиляции */ } // оригинал, но только чтение
```
Правило: большие объекты передаём по `&` (если меняем) или `const &` (если только читаем).

**`for` по элементам:**
```cpp
for (int x : a)  x *= 2;   // x — копия, массив НЕ меняется
for (int& x : a) x *= 2;   // x — ссылка, массив меняется
for (auto& b : buckets)    // auto — компилятор сам выведет тип (тут vector<...>&)
```

## 5. Итераторы (begin/end)

Итератор — «указатель на позицию» в контейнере. `a.begin()` — на первый элемент,
`a.end()` — на позицию ПОСЛЕ последнего. Все алгоритмы STL работают с полуинтервалом `[begin, end)`.

```cpp
sort(a.begin(), a.end());                     // отсортировать весь вектор
sort(a.begin(), a.begin() + k);               // только первые k
int mx = *max_element(a.begin(), a.end());    // max_element возвращает ИТЕРАТОР, * — достаёт значение
int idx = lower_bound(a.begin(), a.end(), x) - a.begin(); // итератор минус begin = индекс
reverse(a.begin(), a.end());
```

## 6. struct и конструктор

```cpp
struct Node {
    int key;
    Node* left = nullptr;     // значение по умолчанию
    Node* right = nullptr;
    Node(int k) : key(k) {}   // конструктор; ": key(k)" — список инициализации, то же что key = k
};
```

## 7. Указатели (нужны для деревьев)

```cpp
Node* p = new Node(5);   // выделить память под узел в куче, p хранит АДРЕС узла
p->key;                  // доступ к полю через указатель (то же, что (*p).key)
p->left = nullptr;       // nullptr — "указатель в никуда", значит ребёнка нет
if (!p) ...              // проверка "указатель пустой"
delete p;                // освободить память (иначе утечка)
```

Почему функции деревьев возвращают `Node*`: например `t->left = insert(t->left, key);`
Если `t->left` был `nullptr`, `insert` создаст узел и вернёт его адрес — и мы его «подвесим» к `t`.
Так не нужны ссылки на указатели (`Node*&`), которые путают новичков.

## 8. pair и structured bindings (C++17)

```cpp
pair<int, int> p = {3, 4};
p.first; p.second;
auto [x, y] = p;              // распаковка: x = 3, y = 4
pair<Node*, Node*> split(...); 
auto [L, R] = split(t, key);  // функция вернула два дерева
```
Пары сравниваются лексикографически (сначала first, потом second) — удобно для кучи.

## 9. Лямбды и компараторы

```cpp
auto sq = [](int x) { return x * x; };   // безымянная функция
sq(5); // 25

// [&] — лямбда видит (по ссылке) все переменные вокруг
int limit = 10;
auto small = [&](int x) { return x < limit; };

// сортировка по убыванию
sort(a.begin(), a.end(), [](int x, int y) { return x > y; });
// компаратор должен быть "строго меньше": для равных возвращать false!
```

## 11. Шаблоны (template)

```cpp
template <size_t N>                    // N подставляется при компиляции
void f(array<int, N>& a) { ... }       // работает для массива любого размера N

template <typename T>                  // T — любой тип
T myMax(T a, T b) { return a > b ? a : b; }
```
`array<size_t, 256>` — массив фиксированного размера (размер известен при компиляции), лежит на стеке, быстрее vector.

## 12. Прочее из кода препода

- `static constexpr size_t BITS = 8;` — константа, вычисляется при компиляции; `static` — видна только в этом файле.
- `namespace { ... }` (анонимный) — функции внутри видны только в этом файле. На контестах не нужно.
- `1 << BITS` — сдвиг: 2^BITS. `x >> 8` — деление на 256, `x & 255` — остаток от деления на 256.
- `++i` vs `i++`: `++i` сначала увеличивает, потом возвращает. `ans[--cnt[d]] = x` — сначала уменьшаем `cnt[d]`, потом используем как индекс.
- `assert(cond);` (`<cassert>`) — если cond ложно, программа падает с сообщением. Для тестов.
- `mt19937 rng(seed); rng()` — хороший генератор случайных чисел (`rand()` плохой: на Windows максимум 32767).
